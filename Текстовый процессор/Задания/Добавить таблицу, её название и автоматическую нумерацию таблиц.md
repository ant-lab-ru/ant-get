## Добавить текст перед таблицей

1. Добавить в конец раздела **Сферы применения** текст ниже и разметить его стилем **Основной текст**

```
Примеры задач, которые решают инженеры-исследователи в разных отраслях, приведены в таблице 1.
```

## Вставить таблицу

1. Добавить пустой абзац после вставленного текста и оставить курсор в нём
2. В верхнем меню нажать **Таблица** -> **Вставить таблицу...**
3. Задать 2 столбца и 4 строки
4. Нажать **Вставить**
5. Заполнить таблицу текстом ниже

| Отрасль       | Пример задачи                                  |
| ------------- | ---------------------------------------------- |
| Электроника   | Разработка датчика для медицинского прибора    |
| Энергетика    | Повышение КПД солнечной панели                 |
| Биотехнологии | Автоматизация измерений в биологическом опыте  |

%% скриншот: окно «Вставить таблицу» %%

> [!NOTE] Примечание
> Абзацы внутри ячеек LibreOffice по умолчанию размечает стилями **Содержимое таблицы** и **Заголовок таблицы**. Их, как и другие встроенные стили, можно настроить под требования к документу.

## Добавить название таблицы

1. Поставить курсор в начало первой ячейки таблицы и нажать **Enter**, чтобы над таблицей появился пустой абзац
2. Вписать в него текст ниже, оставив между словом **Таблица** и тире два пробела

```
Таблица  — Примеры задач инженеров-исследователей
```

3. Поставить курсор между пробелами
4. Зайти в меню **Вставка** -> **Поле** -> **Ещё поля...**
5. Зайти в раздел **Переменные** и выбрать:
	- **Тип:** Диапазон нумерации
	- **Выбор:** Таблица
	- **Формат:** Арабские (1 2 3)
6. Нажать **Вставить**
7. Разметить абзац с названием стилем **Таблица**

> [!NOTE] Примечание
> По ГОСТ название таблицы располагается **над** таблицей, слева, без абзацного отступа. Подпись рисунка, наоборот, располагается **под** рисунком.

## Добавить перекрёстную ссылку на таблицу

1. Удалить вручную вписанную единицу в тексте перед таблицей
2. Вставить на её место перекрёстную ссылку на номер таблицы так же, как ссылку на [[Добавить автоматическую нумерацию рисунков и формул, перекрёстные ссылки|номер рисунка]]
