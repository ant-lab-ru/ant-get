## Инструкция

1. Загрузите данные из файла **data.csv** по инструкции [[Загрузить данные из файла]]
2. Постройте график зависимости напряжения от времени при помощи [[Pyplot]], как в задании [[График напряжений на входе АЦП ПС]]
3. Вместо `plt.show()` сохраните график в файл

``` python
plt.savefig('rc-plot.png', dpi=300)
```

4. Вставьте файл **rc-plot.png** в отчёт по инструкции [[Добавить и разметить рисунки]]

> [!HINT] Совет
> Определите по графику постоянную времени: за время τ напряжение на заряжающемся конденсаторе достигает примерно 63 % от установившегося значения, а на разряжающемся падает примерно до 37 % от начального. Отметьте этот момент на графике и сравните τ с произведением RC по номиналам.
