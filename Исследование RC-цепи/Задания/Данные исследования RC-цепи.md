## Результат

- [ ] В папке **get-rc** репозитория **get** есть [[CSV-файл]] **data.csv** с измерениями напряжения на конденсаторе
- [ ] В первой строке файла указаны названия столбцов с единицами измерения
- [ ] График в отчёте построен именно по этим данным

> [!EXAMPLE] Пример
> Начало файла **data.csv**
> ```
> Время[с],Напряжение[В]
> 0.0000,0.0129
> 0.0213,0.0258
> 0.0425,0.0387
> ```

## Инструкция

1. Если ваш скрипт измерений ещё не сохраняет данные в файл, допишите сохранение по инструкции [[Сохранить данные в файл]] и повторите измерение
2. Положите файл **data.csv** в папку **get-rc**
3. Откройте файл и убедитесь в корректности его содержимого
